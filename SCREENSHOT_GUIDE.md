# Rutiini - Real Screenshot Guide for Google Play 📱

You're calling daycares - let's make this FAST! ⚡

## Quick Setup (2 minutes)

1. **Open your Rutiini app** (`npm run dev`, then http://localhost:5000)
2. **Use Chrome DevTools** to simulate different screen sizes
3. **Take screenshots** using Windows/Mac built-in tools
4. **Upload to Google Play**

---

## Step-by-Step Guide

### PHONE SCREENSHOTS (375x667px)

**In Chrome Browser:**
1. Press `F12` (or right-click → Inspect)
2. Press `Ctrl + Shift + M` (toggle device toolbar)
3. Select device: **iPhone 12** (375×667)
4. Set language to **Finnish** in app
5. Press `Ctrl + Shift + S` → Take screenshot

**Screenshots to capture:**

| # | Screen | What to show |
|---|--------|-------------|
| 1 | Login - Daycare Code | "Päiväkodin koodi" input field |
| 2 | Login - Role Select | "Valitse rooli" with Daycareleader/Staff/Guardian buttons |
| 3 | Login - Email/Password | Login form with email + password fields |
| 4 | Dashboard | Main dashboard with children list |
| 5 | Messaging | Chat/messaging interface |

**Save as:**
- `phone_01_login_daycare_code.png`
- `phone_02_role_selection.png`
- `phone_03_login_credentials.png`
- `phone_04_dashboard.png`
- `phone_05_messaging.png`

---

### TABLET SCREENSHOTS (768x1024px)

**In Chrome DevTools:**
1. Press `Ctrl + Shift + M` again
2. Select device: **iPad Air** (768×1024)
3. Capture same 5 screens

**Save as:**
- `tablet_01_login_daycare_code.png`
- `tablet_02_role_selection.png`
- etc...

---

### CHROMEBOOK SCREENSHOTS (1920x1080px)

**In Chrome DevTools:**
1. Close device toolbar (`Ctrl + Shift + M`)
2. Maximize browser window
3. Adjust window to **1920x1080** if possible
4. Capture same 5 screens

**Save as:**
- `chromebook_01_login_daycare_code.png`
- `chromebook_02_role_selection.png`
- etc...

---

## For Each Screenshot:

✅ **DO:**
- Show real Finnish text ("Päivittäinen merkinnät", "Viestit", etc.)
- Show clean, professional UI
- Capture full viewport including header/footer
- Use real app data if available

❌ **DON'T:**
- Include browser tabs/address bar
- Use placeholder text
- Include cursor or selection highlights
- Add watermarks or effects

---

## Upload to Google Play

1. Go to **Google Play Console** → Your app
2. **Store listing** → **Screenshots**
3. For each device type:
   - Click **"Add screenshot"** (up to 8 per device)
   - Upload your 5 PNG files
   - Write a brief caption in Finnish (optional)

**Example captions (Finnish):**
- `Päivittäin merkinnät` (Daily entries)
- `Viestinta vanhempien kanssa` (Messaging with guardians)
- `Päiväkodin hallinta` (Daycare management)
